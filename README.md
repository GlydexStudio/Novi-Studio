# Novi Studio

Official Android IDE and development environment for the **Novi Programming Language** by **Glydex Studio**.

Novi Studio is designed for phone-first development using Code On The Go. The project deliberately keeps Kotlin sources under the Android source tree and does not place `.kt` files in the repository root.

## What is included

- WebView-based mobile IDE UI (HTML/CSS/JavaScript, no framework, no CDN)
- Real Android Storage Access Framework file explorer
- Open/save/create/rename/delete file operations
- `.novi` file-opening intent handling
- Project manager with a simple `novi.project` manifest
- Official Novi 0.1.1 interpreter source preserved under `tools/novi-runtime/src`
- Generated CommonJS runtime bundle shipped under `app/src/main/assets/runtime/`
- Runtime execution isolated from the visible IDE WebView
- AST-based formatter and parser-backed diagnostics
- Controlled terminal command surface
- Novi Pack update checker/downloader with staging and SHA-512 verification
- Node.js runtime abstraction and explicit capability reporting
- Debugger capability model that does not expose fake controls
- Unit-testable service boundaries

## Code On The Go

The repository contains a minimal Gradle shell, but it is safe to keep the Gradle configuration generated by Code On The Go when importing the `app/` module. The important rule is that Kotlin stays under `app/src/main/java/com/glydexstudio/novistudio/`; no `.kt` source is placed in the project root.

Recommended configuration:

- applicationId: `com.glydexstudio.novistudio`
- compileSdk: 36 or newer
- minSdk: 26

No Kotlin source belongs in the project root.

## Novi runtime

The runtime shipped by Novi Studio is based on the official `novi-language` implementation. The upstream project currently exposes its lexer, parser, AST, runtime values, environment, interpreter, diagnostics and CLI as TypeScript code, and package version `0.1.1` is the package version used by this project.

The Android runtime host does not translate Novi into JavaScript and does not use `eval()` or `new Function()` to implement Novi. The official interpreter code is compiled from the upstream TypeScript implementation and executed as an isolated JavaScript runtime bundle inside a dedicated, invisible runtime WebView. The visible IDE WebView never receives filesystem or shell privileges.

## Node.js / npm

Node.js is now bundled as the real Node.js Mobile 18.20.4 native runtime supplied for this project. The three ABI-specific `libnode.so` files are included under `app/libnode`, and Novi Studio starts the selected library through a JNI bridge and a dedicated background thread.

The embedded runtime currently exposes real Node execution for `node --version`, `node <script.js>`, and `node -e`. The WebView cannot execute shell commands or load `libnode.so` directly.

The supplied Node.js Mobile archive contains the native Node library and headers, but it does not contain an npm CLI payload. Novi Studio therefore does not fabricate an npm version: npm remains a separate capability to be provisioned and verified later. `Novi Pack` can still resolve `novi-language` metadata and downloads directly from the official npm registry.

## Security model

Project code is treated as untrusted. The visible WebView only receives narrowly-scoped bridge methods. SAF URI access is retained by Android and operations are checked against the selected tree. Shell access is never exposed directly to JavaScript. The hidden runtime receives source text only; it has no direct Android bridge.

## Project format

```text
MyProject/
├── novi.project
├── main.novi
├── src/
└── assets/
```

Example `novi.project`:

```json
{
  "schema": 1,
  "name": "MyProject",
  "entry": "main.novi",
  "language": "novi-language",
  "minimumNoviVersion": "0.1.1"
}
```

## Build-time runtime generation

The official Novi TypeScript implementation is kept under `tools/novi-runtime/src`. A small Node build script emits the checked-in browser-compatible runtime bundle:

```text
npm run build:novi-runtime
```

The Android app does not need npm to edit files or execute the already-generated runtime bundle.

## Verification

Before publishing, verify:

1. `app/src/main/java/com/glydexstudio/novistudio/` contains all Kotlin sources.
2. The WebView loads `assets/web/index.html`.
3. SAF folder selection and persistence work.
4. `.novi` intents load the selected file.
5. `say`, variables, functions, conditions, loops, arrays and objects execute using the official Novi runtime.
6. Formatter uses parsed Novi AST nodes.
7. Diagnostics originate from the lexer/parser, not from string guesses.
8. Novi Pack update staging preserves the active bundle until validation succeeds.
9. Node/npm status reports capability rather than fabricated versions.

## Branding assets

Place the official assets supplied by Glydex Studio at:

```text
app/src/main/res/drawable-nodpi/appnovi.png
app/src/main/assets/branding/noviicon.png
```

The source archive produced from this workspace does not invent or redraw these assets when they are not supplied in the source context.
